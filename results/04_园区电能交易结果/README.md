# 三类园区电能交易图

本目录包含当前主方法在三种典型偏好、四个典型日和三个园区下的逐时园区间电能交易图，共 36 张 PNG。

## 图形含义

- 横坐标为典型日的 0 至 23 时。
- 纵坐标为园区间交易电量，单位为 kWh。
- 正值表示本园区从对应园区买入电能。
- 负值表示本园区向对应园区卖出电能。
- 蓝色表示居民区，橙色表示商业区，绿色表示工业区。
- 每张图只显示本园区之外的两个交易对象。
- 同一“园区—典型日”下的三种偏好采用相同纵轴范围，便于横向比较。

## 配套数据

- `peer_trade_hourly_detail.csv`：1728 条“偏好—典型日—时刻—本园区—交易对象”明细。
- `peer_trade_daily_by_counterparty.csv`：按交易双方汇总的典型日电量。
- `validation.json`：图形数据与环境交易记录及 `daily_agent_summary.csv` 的一致性校验。
- `analysis.md`：交易规模、园区角色、双边结构、季节时段规律及论文结论分析。

所有 36 张图均通过校验。园区交易量重构误差和双边买卖反对称误差均为 0，与分园区日汇总表的最大差异为 3.64e-12 kWh。
