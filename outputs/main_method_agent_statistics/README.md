# 主方法分园区调度统计

本目录统计当前主方法在四个 24 小时典型日、三种代表性偏好和三个园区下的调度结果。数据来源为 `strict_v3_all_evolving_kappa0_seed_44`，市场机制为 Carbon-Dividend CDA V3，碳价为 0.01。

## 代表策略

| 偏好类型 | 策略文件 | 帕累托索引 | 训练来源权重（成本，碳排放） |
|---|---:|---:|---:|
| 成本优先 | EP_policy_61.pt | 61 | (0.800000, 0.200000) |
| 相对均衡 | EP_policy_71.pt | 71 | (0.571429, 0.428571) |
| 碳排放优先 | EP_policy_94.pt | 94 | (0.200000, 0.800000) |

三个目标权重依次为 (0.8, 0.2)、(0.5, 0.5) 和 (0.2, 0.8)，权重顺序为（成本，碳排放）。策略选择首先最小化实际权重与目标权重的距离，再优先保留严格测试下的非支配策略，最后分别按最低成本、前沿中部和最低碳排放择优。档案中没有精确的 (0.5, 0.5) 策略，因此相对均衡策略采用距离最近的 (0.571429, 0.428571)。

## 校验结果

全部基础校验通过。统计表最大电功率平衡绝对残差为 2.27e-13，园区间电量最大不平衡为 0，碳红利最大预算不平衡为 1.78e-15，总弃热量为 1.46e-11，可视为数值零。调度图绘图后最大平衡残差为 6.82e-13。

在系统层面，从成本优先转向相对均衡、再转向碳排放优先时，运行成本依次上升、碳排放量依次下降。单个园区和单个季节不要求逐项单调，因为合作式调度会在园区之间转移供能、成本和减排责任。系统偏好响应、物理平衡和市场结算均通过校验，但这些功能性结果不能替代已有的跨算法多随机种子统计比较。
