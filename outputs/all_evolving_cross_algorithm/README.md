# 跨算法帕累托前沿评价说明

`pooled_front_metrics.csv` 对应图 `outputs/figures/all_evolving_cross_algorithm_pareto.png` 中的八条合并帕累托前沿。每种方法汇总随机种子 11、22、33、44、55 的严格 96 小时测试结果，再删除重复点和受支配点。对比方法包括锚点引导进化 MADDPG、固定权重 MADDPG、固定权重 MAPPO、MASAC、MOPSO、固定权重 MATD3 和固定权重 IPPO。

## 原始超体积参考点与距离指标归一化

- 理想点（运行成本，碳排放）：`[233978.826985, 35593.796415]`
- 最差边界（运行成本，碳排放）：`[588256.035046, 257093.855200]`
- 原始尺度 HV 参考点：`[623683.755852 CNY, 279243.861079 kgCO2]`
- 超体积直接根据原始运行成本和原始碳排放计算，不对目标值归一化。
- 归一化公式 `z = (f - ideal) / (nadir - ideal)` 只用于 IGD 和稀疏度，避免不同量纲支配距离计算。

## 指标含义

- 原始超体积越大越好，表示前沿同时具有更好的收敛性和覆盖范围，其单位为 `CNY * kgCO2`。
- 归一化稀疏度按成本排序后，计算相邻点归一化欧氏距离平方的平均值；数值越小只表示相邻点更密。
- 稀疏度会受到点数和前沿覆盖范围影响，不能脱离 HV、IGD 和前沿范围单独用于判断算法优劣。例如，较窄的前沿也可能得到很小的稀疏度。
- 合并前沿指标用于描述图中的总体前沿；论文的统计结论应优先使用表中的五种子均值、标准差和 `paired_tests.csv`。

## 本次正式实验结论

- 当前主方法的五种子平均原始超体积为 `6.203016e10 CNY * kgCO2`，八种方法中排名第一；合并前沿原始超体积为 `6.387375e10 CNY * kgCO2`，同样排名第一。
- 固定权重 MATD3 的平均原始超体积为 `6.064430e10`，固定权重 IPPO 为 `5.654766e10`。当前主方法分别高出约 `2.29%` 和 `9.70%`。
- 当前主方法相对 MATD3 和 IPPO 在五个随机种子上均取得更高 HV 和更低 IGD；单侧配对 Wilcoxon 检验均为 `p=0.03125`。
- 相对锚点引导进化 MADDPG 和固定权重 MADDPG，当前主方法平均指标仍为最优，但五种子检验尚未达到 `0.05` 显著性水平，因此论文中应表述为“综合排名第一并呈稳定提升趋势”，不宜表述为对所有强基线均具有统计显著优势。
- IPPO 的帕累托点数量较多，但 HV 和 IGD 较差，说明点数多不代表前沿收敛质量高。
