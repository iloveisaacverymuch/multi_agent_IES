# 全年真实数据跨算法评价说明

本目录中的结果来自完整非闰年 `8760` 个连续小时的逐时仿真，不是四个典型日的倍数折算。

## 数据与评估口径

- 全年负荷和光伏数据由 `data/raw` 中的原始时间序列按 `scripts/prepare_data.py` 相同的截取、缩放和归一化规则生成。
- 全年数组包含居民区、商业区和工业区各 `8760 x 5` 个状态数据。
- 从全年数组重新抽取1月21日、4月21日、7月21日和10月21日后，与已有96小时测试集逐点一致。
- 每个策略只在年初重置一次电储能和热储能，之后连续运行8760小时，储能状态跨日和跨月延续。
- 每小时汇总三个园区的运行成本和碳排放，全年目标是8760个小时目标的直接累计值。
- Carbon-Dividend CDA V3 的碳价保持为 `0.01 CNY/kg CO2`，与正式对比实验一致。

## 计算规模与完整性

- 评价算法数：8。
- 随机种子：11、22、33、44、55。
- 全年评价策略数：4990。
- 环境交互步数：43,712,400。
- 每个策略同时保存12个月明细；月度求和与全年总量的最大绝对误差为 `4.32e-7`。

## 主要结论

- 当前主方法五种子平均全年原始超体积为 `4.653355e14 CNY * kgCO2`，排名第一；平均归一化 IGD 为 `0.012880`，同样排名第一。
- 当前主方法相对锚点引导 E-MADDPG、MADDPG、MATD3、IPPO、MAPPO、MASAC 和 MOPSO 的平均全年 HV 分别提高约 `0.52%`、`0.68%`、`2.45%`、`10.11%`、`12.65%`、`18.60%` 和 `56.90%`。
- 相对 MATD3、IPPO、MAPPO、MASAC 和 MOPSO，主方法在5个随机种子上均取得更高HV和更低IGD，单侧配对 Wilcoxon 检验均为 `p=0.03125`。
- 相对锚点引导 E-MADDPG 和 MADDPG，主方法平均指标最优，但五种子检验未达到 `0.05` 显著性水平，因此应表述为稳定改善趋势，而不是统计显著优势。

## 文件说明

- `全年帕累托前沿数据.csv`：八种方法合并五个种子后的全年非支配点。
- `年度五随机种子汇总.csv`：各方法五种子的均值与标准差。
- `年度合并前沿指标.csv`：合并前沿的原始HV、IGD相关信息和排名。
- `年度随机种子明细.csv`：每个算法、每个种子的全年指标。
- `年度配对显著性检验.csv`：当前主方法与各对比方法的配对检验。
- 各运行目录的 `annual_test/metadata.csv`：每个保存策略的全年成本和碳排放。
- 各运行目录的 `annual_test/monthly_detail.csv`：每个策略的逐月成本和碳排放。
